# Improving SLSS for Local Community Detection

This repository contains code for experiments on local community detection in social networks.

## Algorithms
- SLSS
- SLSS with Laplacian
- SLSS with GWL

## Project files
- `SLSS.py`
- `SLSS_laplacian.py`
- `SLSS_GWL.py`
- `Metric.py`
- `Metric_laplacian.py`
- `Metric_GWL.py`
- `Function.py`
- `dataset/`

## Requirements
- Python 3.8 or higher
- NetworkX (for graph handling)
- NumPy
- Pandas
- Scikit-learn (if used for metric calculations)

## How to run
To run the main algorithm or its variants, execute the respective Python script from your terminal:

1. **Run standard SLSS:**
   
python SLSS_laplacian.py
python SLSS_GWL.py
